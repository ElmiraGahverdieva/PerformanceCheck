PageSpeed Bulk Checker

Массовая проверка производительности страниц через Google PageSpeed Insights API.
Пустые строки игнорируются. Поддерживаются сотни ссылок — они будут обработаны последовательно с учётом выбранного числа потоков.
Обязательно. Без ключа Google использует общую анонимную квоту — она исчерпана почти всегда. Как получить ключ. Важно: в Google Cloud Console нужно включить PageSpeed Insights API для проекта ключа.
1–5. Больше = быстрее, но выше риск лимитов.
При таймауте/ошибке API запрос повторится указанное число раз.
